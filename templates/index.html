Smart Water
Usage Controller

A dual-engine decision system that fuses fuzzy logic with a trained neural network to convert real-time usage and availability into clear, actionable water-conservation recommendations.

Why conservation matters

The system reduces unnecessary flow when supply is low, guiding users toward balanced, sustainable water consumption.

Dual-engine reasoning

Fuzzy logic applies human-readable rules. The neural network learns patterns from data. Both engines vote — the safer recommendation wins.

Guide

How to use the system

1

Set Water Usage

Drag the usage slider to reflect current water consumption in litres. Lower values indicate lighter use; higher values trigger more cautious recommendations.

2

Set Availability

Adjust the availability slider to represent the current water reserve as a percentage. A low value signals scarcity; a high value signals abundance.

3

Read the Output

The system returns a human-readable recommendation — from "Critical conservation mode" to "Normal flow allowed" — with reasoning from each engine.

Reference

Input and output meaning

Inputs

Water Usage — current consumption in litres.

Water Availability — remaining reserve as a percentage (0 = none, 100 = full).

Outputs

Five recommendation tiers from most to least conservative. The system always picks the safer of the two engine outputs to protect against water shortages.

Critical High Balanced Moderate Normal
